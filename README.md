# Conciencia-digital-y-ciberseguridad
Página web educativa sobre fraude digital: engaños en redes sociales y mensajería, ingeniería social y el papel de la IA en los ataques y en la defensa.  Estática, sin dependencias, sin rastreadores y sin build. Solo HTML, CSS y JavaScript.  ## Contenido  - **Anatomía del engaño** — las seis palancas psicológicas y la regla de las tres preguntas.
